## What Problems Does It Solve?

If you regularly work with spreadsheets, data, text, or images, you've surely run into these frustrations:

- Exported Excel / CSV files that are **messy and dirty**: duplicate rows, extra spaces, inconsistent casing, empty rows and columns…
- Needing to turn tables into **JSON / SQL / Markdown**, but doing it by hand is slow;
- A batch of **images to compress, resize, or watermark**, but online tools require uploading — and you worry about privacy;
- A blob of minified **JSON that's unreadable**, and you want to beautify it or find the error;
- A large chunk of **text that needs batch find/replace, numbering, or sorting**…

**DataForge Pro turns all these high-frequency operations into one-click actions.** Paste your data → check the options → click once → get your result. It's that simple.

## Quick Start (3 Steps)

1. **Open**: Unzip the downloaded package and double-click `index.html`. It opens in your browser.
2. **Pick a tool**: Choose a tool from the home page (use the top search box, e.g. "CSV", "JSON", "image").
3. **Process**: Paste data into the input box (or upload a file) → check the options → click "⚡ Run" → Copy or "💾 Export File".

> 💡 Drag-and-drop file upload is supported; press `Ctrl/Cmd + Enter` to run quickly.

## How to Activate Pro Tools

After purchase, you'll receive a **license key** in the format `DFP-XXXX-XXXX-XXXX`. To activate:

1. Open `index.html`.
2. Click the **license badge** in the top-right corner (where it shows "🔓 Trial"), or the "Enter license key" link in the footer.
3. **Paste your key** into the dialog (make sure there are no extra spaces).
4. Click **"Activate"**.
5. When you see "✅ Valid key! All Pro tools unlocked", you're done. All ⭐ tools are now available.

> Activation status is saved in your current browser. If you switch browsers or clear browser data, you'll need to re-enter the key.

## FAQ

**Q: The page is blank after opening?**
A: Please open with a modern browser like Chrome, Edge, Firefox, or Safari. Right-click `index.html` → Open with → choose your browser.

**Q: Is my data uploaded anywhere?**
A: No. This product performs no network uploads whatsoever — all computation happens locally. You can even use it offline to verify.

**Q: How large a file can it handle?**
A: It depends on your computer's memory. Tables with tens of thousands of rows and normal-sized images run smoothly. For very large files, process them in batches.

**Q: How many devices can one Pro key be used on?**
A: The key can be activated on multiple devices that are your own. Please do not share it with others.

**Q: Which operating systems are supported?**
A: Any system with a modern browser: Windows, macOS, and Linux all work.
